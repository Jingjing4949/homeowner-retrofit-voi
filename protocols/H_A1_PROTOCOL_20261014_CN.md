# H-A1 自适应问询检验：预先登记协议

登记日期：2026-10-14。本协议与 `h_a1.py`、`h_a0.py`、数据缓存清单一起在读取调参集结果前冻结（`FREEZE.json`）；如需修改，必须另写修订说明并保留原文。

## 1. 要回答的问题

H-A0 结论为 QUESTION_VALUE：从宽泛特征（加账单）到完整房屋细节，追回率从 0.623 升到 0.908。H-A1 检验：

1. 在只问少数几个细节问题（预算 K = 1–6）时，**按住户当前回答自适应地选下一个问题**，是否比对所有住户问同一组问题（静态问卷）追回更多差距？
2. 以决策为目标的问题选择（期望信息价值 EVOI），是否优于只关注预测变化或属性不确定性的通用选择准则？

负结果同样是有效结论：若静态问卷已足够，论文方向改为“哪几个问题最值得问”的决策分析。

## 2. 数据、目标与划分（与 H-A0 完全一致）

- 数据、住户筛选、动作集（22 个措施/组合，“不改造”值为 0）、价值 v(b,a) = ΔE·1[ΔB ≥ 0]、权重均同 H-A0，直接复用 `h_a0.load()` 与 `h_a0.split()` 及同一缓存（SHA256 见缓存清单）。
- 训练集内再按 PUMA 以 `HA1-20261014-SEL` 哈希取 10% 作为**选择集**（sel），只用于拟合静态问卷；网络只在其余训练行上拟合，早停用 H-A0 的早停组。
- 结果只在调参集计算；**封存测试集不计算任何指标**。
- 完整性检查：调参集上 FIX_SCZ 与 ORACLE 必须复现 H-A0 的 2555.6 与 3002.9（容差 0.1），结果写入报告。

## 3. 信息设定

- 初始已知 S0 = H-A0 的 BILLS 层（州、气候区、8 个宽泛特征、基准账单、四种燃料用量），共 15 项。
- 问题池 Q = RICH 层中 BILLS 以外的 26 个属性（保温、渗透、门窗、设备效率、风管、设定温度、人数等），每个问题代价为 1，回答即该属性的真实取值。
- 预算 K = 0…6，每户逐个提问；主要终点只看 K ∈ {1,2,3,4}。

## 4. 模型（固定，不调参）

- **价值网络**：对 22 个动作输出预测价值。类别特征各 16 维嵌入（未问的问题用专门的“未知”嵌入），数值特征 log1p 后标准化；MLP 512-512-256，GELU，dropout 0.1；AdamW（lr 1e-3，wd 1e-5），批 2048，30 轮，按早停组损失取最佳轮。训练时每行随机遮盖：已知问题数 k 在 0–26 均匀抽取，随机选 k 个可见。目标除以训练集均方根，按权重加权 MSE。
- **条件分布网络**：同结构，输出 26 个属性各自的类别分布；只对被遮盖的属性计交叉熵（k 在 0–25 抽取）。
- 两种网络各训练 3 个种子（1,2,3 与 101,102,103），预测取平均。
- 推荐：预测最大值 > 0 时推荐该动作，否则不改造。
- 可信度检查：所有 26 题都已知时网络的追回率记为 NN_FULL；若低于 0.85（H-A0 中 GBM_RICH 为 0.908）则标记 `nn_degraded`，结论须降级解释。

## 5. 问题选择策略

| 策略 | 类型 | 规则 |
| --- | --- | --- |
| RANDOM | 自适应（下限） | 随机顺序（固定种子） |
| STATIC_GREEDY | 静态 | 在选择集上贪心前向选择，使所有住户共用的问题组实际价值最大 |
| STATIC_GREEDY_CZ | 静态（分气候区） | 每个气候区单独贪心；选择集不足 500 户的气候区用全国顺序 |
| ENTROPY | 自适应，通用 | 问当前条件熵最大的属性 |
| INFO | 自适应，通用 | 问使 22 个预测价值的期望变化（L2 范数）最大的属性 |
| **EVOI（主方法）** | 自适应，面向决策 | 问期望信息价值最大的属性：Σ_v p(v｜已知) · [max(0, max_a f_a(已知+v)) − f_{a*}(已知+v)]，a* 为当前推荐（不改造时 f=0） |

ENTROPY、INFO、EVOI 的条件分布只取每题概率最高的 6 个取值并归一化，报告被覆盖的概率质量。

## 6. 指标

- 与 H-A0 相同：V、G = V(ORACLE) − V(FIX_SCZ)、追回率 C = (V − V(FIX_SCZ)) / G，按 PUMA 1000 次整群自助法求 95% 区间。
- **主终点** D_static = 平均_{K=1..4}[C_EVOI(K) − max(C_STATIC_GREEDY(K), C_STATIC_GREEDY_CZ(K))]。两种静态问卷在每个自助样本中取较好者（对本方法不利，偏保守）。
- **次终点** D_info = 平均_{K=1..4}[C_EVOI(K) − max(C_INFO(K), C_ENTROPY(K))]。
- 描述性指标：各策略达到 C = 0.6/0.7/0.8 所需题数、各题被问比例、推荐导致账单上升的比例、候选取值覆盖质量。

## 7. 判定规则（预先登记）

间隔阈值 0.02（G 的 2%，约 9 kg CO2e/户·年）：

1. **ADAPTIVE_GAIN**：D_static 区间下界 ≥ 0.02，且 D_info 区间下界 > 0。主方法成立。
2. **ADAPTIVE_GAIN_VS_STATIC_ONLY**：D_static 下界 ≥ 0.02，但 D_info 下界 ≤ 0。自适应有用，但“面向决策”的准则不比通用准则好。
3. **STATIC_SUFFICIENT**：D_static 区间上界 < 0.02。静态问卷已足够，自适应方法不作为论文主张。
4. **INCONCLUSIVE**：其余情况。

不得在看过调参集结果后改阈值、改模型或增删策略再报告为同一检验。
