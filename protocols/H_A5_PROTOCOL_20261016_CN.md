# H-A5 四层信息价值分解（调参集）：登记协议

登记日期：2026-10-16，在任何 H-A5 全国调参集结果之前冻结（`FREEZE.json` 的 `h_a5` 条目）。

## 1. 背景

H-A4 表明，地层导热系数在 ResStock 中逐户抽样、不能按地址获得，它的推荐价值全部来自地源热泵动作。现实中获得它需要热响应测试。本检验把信息来源按获取方式分为四层，在不知道导热系数的起点上重新检验问卷结论，并检验“只给一部分住户做热响应测试”能否拿回大部分测试价值。

## 2. 信息层级

- **T1 记录：** BILLS 层（房屋概况 + 账单与分燃料用量）。
- **T2 住户问卷：** 住户能自己回答的 15 题（建筑类型细分、是否有风管、风管位置、窗户类型、窗墙面积、热水器效率、热水器位置、阁楼类型、地基类型、墙体类型、采暖设定、制冷设定、是否共用系统、居住人数、使用水平）。
- **T3 上门检测：** 10 项（采暖效率、制冷效率、风管漏风与保温、6 类保温、渗透）。
- **T4 热响应测试：** 地层导热系数。

数据、住户、22 个动作、划分、价值定义、四种排放情景、FIX_SCZ / ORACLE、追回率、PUMA 整群自助法均与 H-A2 相同。只在调参集计算。

## 3. 计算

- **GBM 分层链：** T1 → T2 → T3 → T4，H-A0 的 LightGBM 参数。
- **问卷策略（神经网络，H-A1 冻结代码）：** 起点 S0 = T1，问题池为 T2 + T3 共 25 题，导热系数完全不进入模型；五种策略 K = 0…4，以及 25 题全部回答（NN_FULL）。
- **热响应测试分配：** 在训练集上用 T4 特征为每个动作拟合 LightGBM 价值模型，并用 T3 特征拟合导热系数的多分类 LightGBM。对每户计算测试的期望信息价值 EVOI = E_g[max⁺_a f(x, g, a)] − max⁺_a E_g[f(x, g, a)]（max⁺ 含“不改造”= 0）。按 EVOI 从高到低给权重占比 q 的住户做测试：被测住户用 T4 模型推荐，其余用 T3 模型推荐。q ∈ {0.1, 0.2, 0.3, 0.5}。对照：同比例随机测试；“T3 推荐地源热泵就测试”的规则，以及与该规则相同比例的 EVOI 分配。
- **测试价值追回比例：** Φ_q = [C(分配 q) − C(T3)] / [C(T4) − C(T3)]。

## 4. 登记主张（每种情景，95% 整群置信区间）

- **R1 住户问卷有价值：** C(T2) − C(T1) 的下限 > 0。
- **R2 短问卷追回大部分可追回价值：** ρ3 = [C(EVOI@3) − C(EVOI@0)] / [C(NN_FULL) − C(EVOI@0)] 的下限 ≥ 0.5。
- **R3 静态问卷足够：** D_static（K = 1…4 平均）判为 STATIC_SUFFICIENT（上限 < 0.02），判定规则同 H-A1。
- **R4 定向测试有效：** Φ_0.2 的下限 ≥ 0.5，且 Φ_0.2 − Φ_0.2(随机) 的下限 > 0。

四种情景都成立的写为稳健结论；有情景不成立的，注明依赖排放因子。描述量：检测增益 C(T3) − C(T2)、测试增益 C(T4) − C(T3)、T4 剩余差距、D_info、其余 q 下的 Φ、与地源热泵规则的比较、EVOI 的分布与前 q 住户占总 EVOI 的比例、EVOI 提问的问题分布。
