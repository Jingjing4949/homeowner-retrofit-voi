# 候选 A 收益空间检验 H-A0：预先登记协议

登记日期：2026-10-14。本协议在读取任何结果前冻结；冻结后的修改须另记原因，不覆盖原文。

## 1. 要回答的问题

在 ResStock 全国住宅数据上，以“账单不增加的前提下最大化减排”为目标：

1. 看到全部信息的最优推荐（Oracle）比“按州×气候区固定推荐一个方案”好多少？差距太小就说明没有个性化空间。
2. 只凭几道宽泛问题（类似 Buildings 论文中的 LL87 描述符）能追回多少差距？加上账单、再加上房屋细节后又能追回多少？
3. 由此判断后续方法的方向：选问题的价值（问哪些细节最值得）还是决策学习（同样信息下推荐得更准），或者都不值得做。

这是诊断，不是方法有效性的证据，也不是论文结论。

## 2. 数据

- NREL ResStock 2025 Release 1，AMY2018，`metadata_and_annual_results/national/full/parquet/upgrade{k}.parquet`，CC BY 4.0（DOI 10.25984/1876417）。通过 S3 匿名访问只读取所需列，本地缓存并记录 SHA256。
- 只保留 `in.vacancy_status == "Occupied"` 的住户。
- 所有指标按 `weight` 加权。

## 3. 动作与结果

- 主动作集（22 个）：情景 1–18、29–32。排除 19–23（电动车）与 24–28（需求响应），它们不是改造措施。“不改造”始终可选，价值为 0。
- 次动作集（16 个单项措施）：1–14、17、29。只作描述，不参与判定。
- 对每户 b、措施 a：
  - 减排 ΔE = 基准 `out.emissions.total.lrmer_mid_case_15..co2e_kg` − 改造后同列（kg CO2e/年）。
  - 账单节省 ΔB = 基准 `out.utility_bills.total_bill..usd` − 改造后同列（美元/年）。
  - 价值 v(b,a) = ΔE·1[ΔB ≥ 0]；`applicability` 为假时 v = 0（措施不适用，等同不改造）。
- Oracle 价值 = max(0, max_a v(b,a))。

## 4. 划分

按 `in.county_and_puma` 分组，以固定盐 `HA0-20261014` 的 SHA256 哈希分为训练 60% / 调参 20% / 封存测试 20%。**H-A0 只在训练和调参部分计算；封存测试的任何指标都不计算、不保存。**训练部分再按同一方法留出 10% 的组用于 LightGBM 早停。

## 5. 推荐策略

| 名称 | 可用信息 | 方法 |
| --- | --- | --- |
| FIX_GLOBAL | 无 | 训练集加权平均价值最高的单一动作 |
| **FIX_SCZ（主对照）** | 州、气候区 | 每个州×气候区（ASHRAE 2004）选训练集平均价值最高的动作；训练样本少于 100 户的格子回退到气候区，再回退到全局 |
| GBM_BROAD | 州、气候区、建筑类型、年代、面积、层数、采暖燃料、采暖类型、制冷类型、热水燃料 | 每个动作一个 LightGBM 回归器预测 v，取预测最大者；全部预测 ≤ 0 时不改造 |
| GBM_BILLS | BROAD + 基准年账单、各燃料基准年用量 | 同上 |
| GBM_RICH | BILLS + 采暖/制冷效率、风管、各部位保温、渗透、窗、热水器效率与位置、阁楼/地基/墙体类型、设定温度、共享系统、地层导热、人数、用能水平 | 同上 |
| ORACLE | 全部结果 | 逐户取最优 |

具体列名在脚本中固定。LightGBM 固定设置：num_leaves=63，learning_rate=0.05，min_data_in_leaf=100，feature_fraction=0.9，最多 2000 棵树，早停 50 轮（只用训练集内部留出组），不调超参数。

## 6. 指标

在调参部分计算：

- V(π)：加权平均价值（kg CO2e/户·年）。
- 差距 G = V(ORACLE) − V(FIX_SCZ)，相对差距 r = G / V(ORACLE)。
- 追回率 C_t = (V(GBM_t) − V(FIX_SCZ)) / G，t ∈ {BROAD, BILLS, RICH}。
- 以 PUMA 为单位的 1000 次自助法 95% 区间（种子 20261014），针对 G、r、各 C_t 与 C_RICH − C_BROAD。
- 描述性指标：Oracle 动作分布、Oracle 选择不改造的比例、各策略推荐中适用但账单上升（ΔB < 0）的比例。

## 7. 判定规则（主动作集）

1. **NO_HEADROOM**：r < 0.10，停止候选 A。
2. 否则分别检查（可以同时成立）：
   - **QUESTION_VALUE**：C_RICH − C_BROAD 的 95% 下界 ≥ 0.10，后续方法方向为按信息成本选问题。
   - **DECISION_GAP**：1 − C_RICH ≥ 0.20，后续方法方向为面向决策的学习。
   - **BROAD_SUFFICIENT**：C_BROAD ≥ 0.90 且上两项都不成立，宽泛信息已足够，方法空间小，倾向停止。
3. 都不成立时记为 **WEAK_HEADROOM**，交作者决定。

## 8. 完整性检查（在读取指标前执行）

- 各情景文件 `bldg_id` 集合与基准一致。
- `applicability` 为假的行，其账单与排放与基准相差不超过 1e-6 的相对误差；不一致的比例写入报告，按第 3 节规则仍置 v=0。
- 记录各输入列缺失率；缺失作为独立类别处理。
