# H-A2 信息价值分解的稳健性：登记协议

登记日期：2026-10-15，在读取本检验任何调参集结果之前冻结（`FREEZE.json` 中的 `h_a2` 条目）。

**背景：** H-A1S 显示，可按地址获得的属性（地层导热系数）贡献了最大一块推荐价值；自适应提问相对静态问卷的优势显著但很小（STATIC_SUFFICIENT）。论文因此改为“信息价值分解”：量化公开/地址信息、少量问卷题、全部问卷信息各能追回多少逐户最优推荐的价值。本检验在作出这些主张之前，先检查它们是否依赖某一种排放因子或某一种学习器。分解的划分方式是看过 H-A0、H-A1、H-A1S 的主情景结果后定的；本检验只确认这些主张能否在未看过的情景下成立。

## 1. 固定不变

住户、动作集、划分（含选择集）、账单约束、FIX_SCZ 与 ORACLE 的定义、追回率 C、PUMA 整群自助法（1000 次）都与 H-A0/H-A1 相同。信息划分采用 H-A1S 的 S1：S0 = BILLS 层属性 + 地层导热系数；问卷 Q = 其余 25 题，代价相同。神经网络、各策略和 GBM 参数都沿用冻结代码。只在调参集计算，封存测试集不计算。

## 2. 情景

价值 v(b,a) = ΔE·1[ΔB ≥ 0] 中的排放差 ΔE 依次用四种 Cambium 2024 排放因子：

1. `lrmer_mid_case_15`（主情景，长期边际、中间情景、15 年）
2. `lrmer_high_re_cost_15`（可再生能源成本高）
3. `lrmer_low_re_cost_15`（可再生能源成本低）
4. `aer_mid_case_avg`（平均排放因子，中间情景）

账单节省 ΔB 与情景无关。每种情景下各自重新计算 FIX_SCZ、ORACLE，并重新训练全部模型。

## 3. 每种情景计算的量

- GBM 分层链（H-A0 的 LightGBM，每个动作一个回归器）：BROAD → BILLS → S0 → RICH（全部特征）。
- 神经网络链（H-A1 的网络，3 个种子）：S0 下不提问（EVOI@0）、K = 1…4 的五种策略（ENTROPY / INFO / STATIC_GREEDY / STATIC_GREEDY_CZ / EVOI），以及全部回答（NN_FULL）。

## 4. 登记的主张

每种情景都用 95% 整群置信区间检验：

- **R1 地址信息有价值：** C(GBM_S0) − C(GBM_BILLS) 的置信下限 > 0。
- **R2 短问卷追回大部分可追回价值：** ρ3 = [C(EVOI@3) − C(EVOI@0)] / [C(NN_FULL) − C(EVOI@0)] 的置信下限 ≥ 0.5。
- **R3 自适应提问没有实用优势：** 按 H-A1 定义的 D_static（K = 1…4 平均）判为 STATIC_SUFFICIENT，即置信上限 < 0.02。

四种情景下都成立的主张，在论文中写为稳健结论；有任何情景不成立的，论文须注明它依赖于排放因子的选择。

只描述、不设门槛的量：账单信息增益 C(BILLS) − C(BROAD)、问卷信息增益 C(RICH) − C(S0)、D_info、NN_FULL 剩余差距 1 − C(NN_FULL)，以及两种学习器在 S0 和全部特征下的差距。

## 5. 完整性检查

主情景下，FIX_SCZ 和 ORACLE 的价值应等于 H-A0 的 2555.6 / 3002.9；GBM 的 BROAD / BILLS / RICH 追回率与 H-A0 的 0.582 / 0.623 / 0.908 相差应小于 0.01（线程数不同，LightGBM 可能有微小差异）；神经网络部分应复现 H-A1S S1 的结果。不一致时先查明原因，再解读结果。
